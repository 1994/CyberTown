# 奶茶店与门前街区画面打磨

本轮直接修改游戏中的实时 3D 场景，保留低多边形霓虹风格。截图来自独立验收存档，不改用户预览存档。

## 改动

- 店铺周围加入街面、路缘、灯柱、花槽与远景建筑，消除黑底悬浮感。装饰位于客人工作范围之外，静态批处理降低绘制开销。
- 工作区铺木地板，客席改用疏一些的地砖；增加木质地基、黄铜收边和壁灯。
- 加入角色/柜台阴影，调整环境光与暖色主光；低画质模式不启用阴影。
- 人物从0.92放大至1.03，托盘饮品放大35%，收紧镜头与桌面端操作栏，提高动作可读性。
- 门头字体改为按牌面比例排字，去掉厚重白色光晕；缩短雨棚，露出后墙菜单。
- 店外增加窗框、展示杯、侧墙木格栅；集市补上台面货品和灯带，所有物件保留在既有摊位范围内。
