# Game typography and controls

Original outlined Chinese wordmark, inspired by the angular yellow/cyan art direction at https://www.cyberpunk.net/index.php/us/en/cyberpunk-2077 . Local ZCOOL QingKe HuangYou display font (Google Fonts, OFL license in public/fonts). The wordmark uses local vector outlines, skew, cuts and extended strokes; it does not copy the Cyberpunk logo.

Verified typecheck + production build; desktop identity/confirmation, cinematic entry/skip, mission phone, travel to shop, preparation screen and hiring tabs. 320px and 390px login layouts checked. Final small-control font sizes increased after screenshots; KIM headings excluded from display typography. Test DB only; preview DB preserved.
