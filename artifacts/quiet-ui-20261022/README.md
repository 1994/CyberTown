# 游戏画面去除冗余文字

清除顾客/员工头顶姓名、岗位和状态，入口、点单屏、茶桶、封口机的解释标签，以及场景底部流程文字。顾客低耐心时保留警示条，送达保留短暂勾选反馈；岗位按钮、店招和菜单保留。

营业常驻长句改为简短工作状态，制作/端送只显示动作、数量及必要的自动标记。原料使用图标和数量。订单详情和简短教学收进“怎么玩”，首玩引导仍可跳过并记忆。长提示保留给读屏，不占视觉画面。
