# 赛博小镇 · 第一章 UI 分镜与实现基线

状态：已由Claude接入tea.2界面，真实指派与结算由服务端负责。美术沿用赛博黄青工业街、卡通面具人物，只有招募街区与奶茶店两个场景。当前实现与证据见 [主线验收](REVIEW-TEA-CHAPTER.md)。

## 通用规则
- 镜头3/4俯视，优先看清人物、岗位和队列；突出未接管或拥堵的岗位，其余降灰，工位按钮保持稳定。
- 目标短句 ≤16 字，固定在左上一行；无日志、无多页教学。卡片详情、账本、曲线默认折叠为“详情 ▸”。
- 用动作代替文字：顾客头顶只显示状态小图标（⌛等候/🥤取杯/✕离开），员工头顶亮灯色 = 正在做的岗位（青=前台，橙=制作，黄=主角批次）。
- 顾客动线借鉴 Dave 的可读服务：门口 → 前台排队 → 接单 → 取饮区等候 → 出杯取走 → 离店；同一顾客全程同一人物，杯子只在做好后才出现在出杯口。
- 主角“半自动”：点发光工位 = 指派一批（≤3 单或约 12 模拟秒），主角自己走过去执行；执行中头顶出现 3 格进度点，完成后回待命并轻闪一次。同事永远不需点名。

## 六个关键镜头
| # | 镜头/构图 | 目标短句 | 唯一主操作 | 自动反馈 |
|---|---|---|---|---|
| 1 接手小店 | 街区远景推入店门，门头霓虹点亮，第一位顾客走向前台 | 今晚把店开起来 | 「开门」大按钮 | 镜头落到店内全景，主角站前台 |
| 2 独自试营 | 店内全景：前台、制作台、取饮区三段从左到右一字排开，主角居中 | 先接待这批客人 | 点发光工位指派主角 | 主角走位接单/制作；另一端积压时该工位排队变长并转橙 |
| 3 招第一位 | 切回街区，同事站成一排，制作专长者脚下发光 | 请位同事帮你出杯 | 点选同事 → 放到制作位 | 同事走进店站到制作台，自动开始出杯；制作队列按实际模拟变化，岗位/能力不匹配时仍可能拥堵，不保证消失 |
| 4 验证分工 | 同镜头 2，制作端由同事接管，前台成为唯一发光点 | 你只管前台 | 指派主角接待 | 前台排队可见缩短/仍堵，暗示下一位该招谁 |
| 4→5 招第二位 | 回街区，接待专长同事脚下发光 | 让 TA 接管前台 | 点选同事 → 放到前台 | 同事走进店站上前台；主角让出前台转为机动，凑齐三人 |
| 5 正式高峰 | 三人就位全景，顶部细条：时间/完成÷目标/两端队列/库存 | 撑过高峰，出 72 杯 | 「正式开店」；营业中仅在主角待命且有积压时亮“支援”提示 | 同事持续自动循环；主角执行支援批次；可 x2/跳过，不重复结算 |
| 6 收益焕新 | 结算卡居中偏下，背景店面；达标后门头与招牌换档 | 用收益升级门店 | 「升级」（正式达标才可点） | 真实到账数字滚动，门头焕新，三人庆祝；“详细报告 ▸”展开工资/曲线/技能 |

开店前筹备（镜头 5 之前）只露四行：岗位、备货、策略、预算 vs 钱包；营业中锁定。

## 手机布局
- 竖屏：3D 画面占上 58%，底部 sheet 占 42% 且只放当前一个主操作按钮 + 一行目标；详情上拉展开。
- 3D 区域按实际剩余高度取景，保证三人、前台队列、出杯口完整可见；招募卡横向滑动，只露名字/擅长/工资。
- 横屏（如 844×390）：3D 左 64%，右栏 36% 内容可滚动，主按钮吸底。
- 点击目标 ≥44px；指派直接点 3D 工位光圈，同时在 sheet 提供同名按钮兜底。

## 交付边界
- 0/1/2 名同事时主角需指派次数的减少，靠真实模拟数据呈现，不写死文案。
- 不做逐杯端盘、清台、按时机倒饮料等小游戏；不加支线与任务系统。
