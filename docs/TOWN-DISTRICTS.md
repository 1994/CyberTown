# 赛博小镇街区规划

共享广场是到达和社交枢纽，西侧商业街集中经营与店铺，东侧娱乐街集中休闲地标。玩家可以自由行走，也可以选择目的地沿实际路线步行过去。北区保留扩展街口，新增区域时继续接入现有街道。

| 区域 | 作用 | 识别方式 |
| --- | --- | --- |
| 共享广场 | 新玩家到达、见面、可选招募 | 中央圆形广场、喷泉、招募点 |
| 商业街 | 奶茶经营、集市与后续商业设施 | 暖色店窗、条纹雨棚、连续低层街屋 |
| 娱乐街 | 闲逛、花园、合影与后续娱乐设施 | 紫青灯带、娱乐店面、休闲地标 |
| 北区 | 后续扩展 | 规划标识及施工围挡 |

街机厅、合影馆、舞台及新增街屋外观不代表对应玩法已经开放。奶茶店和广场招募继续使用原有交互距离；导航不会自动接任务、进入店内或开始营业。

规划数据集中在 `shared/townPlan.ts`。街屋占地和新增立柱同时进入 `shared/world.ts` 的碰撞数据，3D 场景、小地图和导航使用相同位置。变更碰撞后运行 `node scripts/export-player-contract.ts --write` 更新 CLI 地图契约，再运行地图、碰撞和默认 Web 检查。

验收覆盖区域文字、真实步行、手动操作中断导航、到达店门后的显式交互、桌面与触屏竖横布局，以及导航不改变任务或金币。新地图证据存放在 `artifacts/town-districts/`；完整经营流程仍使用现有回归测试。
