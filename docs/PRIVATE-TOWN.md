# 私人小镇经营养成

## 分阶段交付

| 阶段 | 交付 | 验收重点 |
| --- | --- | --- |
| 1（本轮） | 经营模型、雇佣大厅、员工派工及店铺筹备衔接 | 签约、培养、派工与流转形成闭环，金币和归属可核对 |
| 2 | 员工养成表现与经理代管深化 | 职级、工作效率、岗位解锁和管理决策有实际差异 |
| 3 | 同事小镇互访 | 默认独处，主动参观；访客只读 |
| 4 | 街区建设与霓虹都会 | 金币和经营积累换来可见的建筑规模与繁荣度 |

私人房间隔离、员工与建设数据作为基础保存；本轮 UI 聚焦第1阶段，不用互访或城市宏景分散雇佣大厅的体验。

## 经营模型

主循环是 **接经营任务 → 决定独自营业还是雇佣 → 安排岗位、备货与策略 → 玩家半自动补位、员工自动工作 → 看经营报表 → 把利润投向员工与门店**。派工是低门槛、持续的基础收入；店铺经营提供更高利润和主要经营目标。

玩家负责开店前的配置和最后确认；开店后主角按批次接待、制作，员工无需逐次指挥。营业自然结束后弹报表，解释收入、成本、净增金币、流失顾客和瓶颈。员工越合适、岗位搭配越完整，主角需要补位的次数越少。开门确认、报表确认都不能省略。

### 单一金币账户

| 流向 | 原型规则 | 玩家需要看清的内容 |
| --- | --- | --- |
| 初始资金 | 原账户600 + 一次性开店补助1400 | 合计2000，补助不重复发 |
| 首次签约 | 首份120；同一来源分身全服每多雇一份，后续报价×1.25，向上取整到10，封顶10000 | 报价、已雇佣数量、涨价原因；每镇同一来源至多持有一份，可转让 |
| 正式营业 | 开门预付原料、运营及当班工资，结束后收入到账 | 雇佣费与每班工资分开，避免误以为买完就没有用工成本 |
| 派工 | 对外完成保洁、补货、巡检合同，显示每周期净收入；自动持续工作 | 自家扫地不会凭空产钱，基础收入来自对外杂活订单 |
| 试营业 | 免费，不改变钱包，不推进正式盈利目标 | 用来试岗位和策略 |
| 门店升级 | 600、1200，分别解锁下一档门面和经营挑战 | 真正花钱，真实改变客流、售价与目标 |
| 考察奖励 | 每据点一次30，共120 | 探索奖励不能重复刷，不算累计经营收益 |

累计经营收益只计正式营业的正向净收益与已结算派工收入，启动金、试营业和考察奖励不计入。钱包是当前可花金币，累计收益是长期经营积累，两者在界面分开。

### 员工成长与岗位

| 职级 | 经验门槛 | 当前解锁 | 经营作用 |
| --- | --- | --- | --- |
| Lv1 学徒 | 0 | 街坊保洁、邻里补货 | 先做杂活；不能直接安排制作、收银或经理工作 |
| Lv2 店员 | 累计60XP | 奶茶店收银、制作、机动补位 | 成为可排班员工；从派工召回后才能入店 |
| Lv3 经理 | 累计180XP | 经理巡检、店内自动机动补位 | 管理类工作开启，三属性随成长提升；更完整的代管玩法在第2阶段深化 |

三属性分别说明服务、制作、应变潜力；每升一级各增加10点，上限99。同事的真实职位或工作绩效不决定游戏职级。正式营业给参班分身20XP；免费试营业不给可刷的成长奖励。

| 自动工作 | 演示周期 | 每周期净收入 | 每周期经验 |
| --- | --- | --- | --- |
| 街坊保洁 | 20秒 | 12金币 | 20XP |
| 邻里补货 | 30秒 | 18金币 | 20XP |
| 经理巡检（Lv3） | 60秒 | 60金币 | 30XP |

派工一次后持续自动工作，玩家可召回或换工作；每位分身同一时间只做一项工作，不能同时在店里营业和外出派工。每镇可雇12位，单场奶茶经营仍带0–2位，避免筹备界面变成拥挤的十几人排班表。离线按服务端时间结算，最多累积8小时；这些短周期是供5分钟演示体验的初值，长期版本需经真实试玩调参。

### 五分钟新手节奏

| 时间 | 玩家行为 | 得到的反馈 |
| --- | --- | --- |
| 0:00–0:30 | 进入自己的小镇，知道移动、手机和雇佣大厅入口 | 不在登录页讲救店剧情；任务由手机接取 |
| 0:30–1:15 | 可先雇一位学徒派去杂活，也可独自去奶茶店 | 先看到雇佣扣款与自动工作状态；招募不阻塞主线 |
| 1:15–2:45 | 配置自己岗位、备货与策略，确认开门并完成首班 | 主角半自动操作，有清楚的忙闲、顾客队列与营业结束 |
| 2:45–3:30 | 看净赚和瓶颈报表，回雇佣大厅 | 看到派工收入、经验与Lv2店员解锁 |
| 3:30–5:00 | 召回店员、安排入店，再开一班或升级门店 | 对比员工加入前后的操作负担与营业结果 |

独自开店可以赚钱，第一局不强制失败；雇人之后更轻松，玩家愿意为了下一个岗位和更好的阵容继续玩。

## 雇佣大厅 UI 要求

大厅要像游戏里的招聘中心，不做长篇说明或海报。桌面采用“招聘 + 我的员工 + 交易市场”明确分区；触屏先选人，再展开详情与雇佣动作。最重要的信息依次是头像姓名、适合工作、雇佣价格、当班工资、当前金币。

- 候选卡：真实或演示身份标识、三项能力、工作潜力、当前报价及涨价来源。
- 详情：解释当前Lv1能做什么、下一职级解锁什么；雇佣按钮直接写价格。
- 我的员工：显示等级、经验、当前工作、下次收益倒计时、累计收入，派工/召回按钮清楚。
- Lv1的店员与经理岗位需明确标锁并说明条件；正在外出工作的员工不能同时安排进店。
- 雇佣成功要有头像进入员工列表、金币变化和可立即派工的反馈；报价变化或余额不足有原位提示。
- 初次雇佣、后续养成和店铺筹备保持同一套名称、角色外观、工资和金币数字。

最新定位以玩家自己的小镇为核心：默认只有本人，进入同事小镇需要主动参观；已雇佣的同事分身是本镇员工，不占用或夺走别人的员工。

同一分身每被全服成功雇佣一次，下一次报价上涨25%并向上取整到10金币；每座小镇可雇一份。雇佣付费、报价检查、员工归属和计数同事务保存，重试不能重复扣钱。旧经营存档保留。

分身从Lv1做保洁、补货等杂活起步，Lv2解锁店员工作，Lv3解锁经理巡店。派工后自动计时完成、结算收入和经验，不需要逐步操作分身；离线后回来按服务端时间结算一次。员工可持续养成，真实同事能力仍使用游戏属性，不对应工作绩效。

金币只有一套。营业盈利和派工收入积累发展收益，城镇升级同时要求金币投入与累计经营收益。城镇从初创小镇逐步建设为商业街区、繁华城区，最终成为霓虹都会。等级与已投入建设持久化，参观时展示镇主自己的等级、员工和店面；访客不能操作镇主的钱包或经营。

首店救店任务仍从手机接取，招募可选，独自营业可起步。地图扩展和四处考察保留，作为后续选址和探索空间。原先“大家默认出生在共享广场”的产品假设由本定位替代；旧通用世界API保留兼容隔离验证。

## 员工合同流转（本轮）

取消永久绑定。雇佣的是可培养、可转让的游戏员工合同，不是现实同事本人。同源分身可由不同镇主独立签约；同一份已培养合同在成交时从卖家移交买家，经验和等级全部保留。

- 招聘：签约新的Lv1员工，沿用全服累计签约需求报价；二手交易不新增分身，不推动首次签约报价，也不因卖出回落。
- 我的员工：培养、自动派工、召回、入店排班；闲置员工可输入10–100000的整数金币挂牌。外出员工先召回，在营业的员工等本班结束。
- 交易市场：看姓名、三项能力、等级经验、卖家、价格；购买前确认真实扣款。自己的在售合同可撤单，成交后显示历史与到手金额。
- 挂牌中的合同仍占卖家12人名额，但不能派工或排班；撤单不收费，恢复员工可用。挂牌不自动到期，玩家可持续流转而无永久绑定。
- 成交收卖家5%手续费，向上取整；买家扣标价，卖家得标价减手续费，手续费有系统账本记录。买方同源已有员工、自己出售的合同、本人分身、名额已满或金币不足均不能购买。
- 挂牌价格不能直接修改：撤单后重新挂牌，避免确认期间价格暗变。同买家的重复购买请求只返回成交结果；并发抢单只能一个买家成功。
- 每次挂牌有独立请求标识，重试不重复挂牌；撤单和成交记录保留。卖出员工不撤销此前杂活收入与历史经营积累。交易收入进入同一钱包，不计入累计经营收益，避免靠倒手刷城市等级。

大厅的说明使用短标签与确认明细，不把规则堆成首次进入的长文。经营主线仍由手机任务推进，招聘和交易均为可选，独自营业可以起步。

## 本阶段接口

所有接口沿用现有登录会话；客户端只提交意图，不写金币、等级或经验。

| 接口 | 请求 | 返回与作用 |
| --- | --- | --- |
| POST `/api/tea/town/enter` | `{ownerId}`，本人可省略 | 建立/进入本人私人小镇，初始化一次性开店补助；保留已有钱包 |
| GET `/api/tea/town` | 无 | TownHome：本人钱包、候选报价、员工、工作、市场与交易记录；按服务端时间结算派工 |
| POST `/api/tea/town/hire` | `{sourceId,expectedPrice}` | 签约Lv1分身，报价变化返回409，不预扣款 |
| POST `/api/tea/town/jobs` | `{cloneId,kind}` | clean/stock/manage持续自动派工；rest召回 |
| POST `/api/tea/town/market/list` | `{cloneId,price,requestKey}` | 挂牌并锁定员工；相同key重试不重复挂牌 |
| POST `/api/tea/town/market/withdraw` | `{listingId}` | 仅卖家撤单，恢复员工可派工与排班 |
| POST `/api/tea/town/market/buy` | `{listingId,expectedPrice}` | 同事务扣款、记手续费、转移员工；同买家重试不重复支付 |

TownHome.market提供最近100个在售合同，trades提供自己的在售及最近交易记录。成交记录保留姓名、来源、等级、经验、标价、卖家和手续费。源同事身份仍由原SPI与游戏配置提供；源同事的现实职级不影响游戏成长。

后端预留的参观与城市等级数据不等于本轮已有相应完整玩法；本轮验收以独享小镇、员工流转和经营衔接为准。
