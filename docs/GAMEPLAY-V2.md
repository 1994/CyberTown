# 自由探索与社交改版

## 问题判断

本轮先在真实网页进入游戏、跳过片头、查看默认引导与主界面。当前证据：[初次引导](../artifacts/redesign/01-before-guide.png)、[办公室](../artifacts/redesign/02-before-office.png)。

1. 进入游戏：片头之后出现覆盖大半场景的长指南。能解释规则，但开始行动前阅读负担过重；改为一句操作提示，细则主动展开。
2. 默认主界面：市场、排行榜、团队技能和下一步同时占用屏幕，玩家主要在卡片之间操作。保留现有美术与交易反馈，压缩常驻 HUD，把主要操作移到地图人物身边。
3. 空间与社交：当前画面中的自己坐在桌后，没有直接控制入口，其他账号表现为榜单条目。改为真实玩家同屏走动、靠近互动，区分在线玩家与可签约的虚拟分身。

本轮截图可确认遮挡、信息密度及可见入口，不能据此宣称完成无障碍审计。键盘焦点、移动设备触控与动态效果仍须在改版实机中验证。

## 一句话玩法

**逛园区，遇同事，招进队，赚金币。**

第一次进入不讲经济公式：先让玩家走起来，附近有可互动对象，点开时只出现姓名、能力、价格与一个主要动作。花币仍明确确认，账单在需要时展开。原有金币、分红、三人队伍和加价挖角规则保留。

## 空间设计

世界范围 60×44，原办公室 17×12；边界面积约为原场景 12.9 倍。面积只是容纳活动的条件，验收重点是路径连续、每个区域有可做的事。

| 区域 | 位置中心 x,z | 玩家去这里的理由 |
| --- | --- | --- |
| 共享广场 | 0,11 | 出生、看到真人、碰杯、查看队伍 |
| 办公区 | 0,0 | 看团队工作、入职和离职演出 |
| 咖啡区 | -17,0 | 见面、挥手、短句交流 |
| 人才街 | -16,-13 | 发现并招募虚拟同事 |
| 项目区 | 18,0 | 用一个主要输入完成短项目 |
| 露台花园 | 18,-13 | 探索、停留、遇人 |

地标提供方向和步行目标，不能用瞬移冒充探索。固定斜俯视镜头平滑跟随玩家，保留总览能力；家具与边界提供基本碰撞。地图应优先形成环路，减少走到尽头再原路返回。

## 社交的三个层次

- **看见**：真人的当前位置和移动跨客户端同步；离线身份不充当在线玩家，NPC 明确区分。
- **回应**：挥手、跳舞、咖啡动作与最多40字的头顶短句同步；先有低门槛表达，再要求输入聊天。
- **产生共同结果**：距离不超过4米的两位在线玩家可碰杯，各得15金币；每对玩家60秒冷却，双向共享冷却且重启保留，奖励写入真实钱包与流水。再由招募、挖角与补偿形成持续关系。

碰杯是轻量合作起点，不能把它等同于完整公会/关系系统。多人局是否让玩家愿意停留，需要真实用户试玩观察，当前不声称已验证留存。

## 验收要点

- 进入10秒内可自由行动；首次无长指南和默认市场遮挡。
- WASD/方向键、点击地面和移动触控能连续走过不同区域；打开输入框不误移动。
- 两个身份互相看到同一位置上的对方，移动和表情同步；断线重连补齐状态。
- 近身碰杯两人真实各+15；远距离、离线和重复请求不能发奖。
- 招募、挖角、技能与赚钱仍真实生效，界面只在相应动作出现必要信息。
- 390×844与桌面实机检查；截图不足以确认的键盘、碰撞、时序和网络行为单独验证。

当前仍使用四个明确标记的测试身份，不含正式SSO、跨服地图、生产级移动防作弊或社交内容治理。
