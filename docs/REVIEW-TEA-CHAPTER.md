# 赛博小镇 · 半自动主线验收

日期：2026-10-21。结论：**tea.2首章与门店升级主线已实现，并通过独立验收**。此前只有设计稿的半自动章节，现在已有真实会话、操作、进度、结算和存档。

## 已完成的可玩流程

独自免费试营 → 招第一位制作同事 → 双人免费试营 → 再招前台同事 → 备货/排岗/选策略 → 正式高峰 → 真实收益 → 花600焕新小店完成首章 → 花1200升级旗舰完成主线。全程只有招募街区与经营两个场景，不加支线。

主角点一次安排一批工作，执行与交付自动完成；批次结束后待命。最多可预排一批，连续点击不会提速。同事持续自动接活，跳过营业也不会给主角代点。顾客到店、接单、制作、取杯与离开使用同一身份和真实服务端状态。

教学分别为8人、18人，正式高峰80人/72杯达标；完成页明确标注不同客流规模。相同18人客流的独立核心实验，0/1/2名同事均完成18杯，主角所需指派分别16/10/0次。该结果证明雇佣确实减少操作，不把教学不同客流的成绩直接比较。

## 真人UI验收

- 桌面正常速度完成全主线，没有跳过或x2：独自8杯（47.3秒）、双人18杯（61.7秒）、正式80杯（62.8秒）；含招聘、升级的自动操作总时长2.9分钟。新手选人、筹备和阅读另留1–2分钟，按约5分钟体验设计；这不是用户研究测得的固定时长。
- 桌面验证双人营业中刷新恢复、正式开门响应丢失后同键重试、真实结算、两次升级与完成态刷新。
- 手机390×844完整章节通关，844×390横屏筹备可操作；教学使用加速/跳过，正式高峰真实完成80杯。两种视口无横向溢出，无页面运行异常。手机验收是Chrome视口模拟，尚未做实体手机兼容测试。
- 正常画质验收覆盖街区/筹备/营业/高峰/结算五段配乐、点击解锁声音、音乐单独静音、总静音、音量保存和跳过无音效爆发。保留赛博黄青夜景、工业店面、卡通面具人物和原创电子配乐。

## 经济与可靠性

正式案例：金币2000，开门预付1080后920，结束销售1600与达标奖200到账后2720；利润520另加奖金200。升级后2120，再升旗舰后920。免费试营不改变金币、正式次数、员工工资或有酬名额。

服务端对开门、推进与终局结算都验证幂等；当前revision、指派时刻、招聘授权和名额不可由客户端绕过。并发开门只扣一次，重复终局只结算一次。真实同事工资即使失败也发放。独立重开SQLite连接可恢复进行中的操作和章节，旧存档不重置。原8787服务与数据未改动。
