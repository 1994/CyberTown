# 模式建议：职场生活社区

这是用户提出“参考《集合啦！动物森友会》”后的策划分析，**其中的布置、送礼、异步来访和合约调整属于建议，尚未实现**。本轮已在开发的自由行走、共享园区、近身互动与轻量项目是兼容这条方向的底座。

## 借鉴的重点

任天堂的官方介绍包含自由探索、收集、布置自己的社区、与居民交流、赠礼和朋友互访。这里借鉴活动与社交的组织方式，继续使用自己的职场题材、美术和角色。

- [任天堂：探索岛屿](https://animalcrossing.nintendo.com/new-horizons/explore/)
- [任天堂：游戏介绍](https://www.nintendo.com/us/store/products/animal-crossing-new-horizons-switch/)

我的设计判断：让玩家愿意回来的主轴应是“我的地方、认识的人、今天的小变化”。财富榜和挖角负责提供可选的短时戏剧性。

## 建议的主循环

**探索 → 做一件小事 → 得到物品 → 布置空间 → 邀请朋友。**

一次五分钟体验可以是：在咖啡馆遇到同事，帮忙完成一个短委托，得到一盆植物，摆在自己的工位上，再邀请朋友来坐坐、合照。短委托、收集和展示分别解决当下操作、成长目标与社交话题。

## 与挖角的关系

温馨社区的长期积累，与随时被别人强制拿走珍惜角色存在冲突。建议把长期好友/住民和临时项目合同分开：好友与收藏保持归属，允许流转的是短期合作合同。更激烈的抢人可以作为限时派对活动，进入前明确规则、结束后恢复。

**当前代码仍保留原始签约/加价挖角规则，没有擅自迁移这套经济系统。** 需要先验证玩家到底更喜欢经营生活还是抢人竞争，再决定主次与迁移。

## 空间和节奏

公共广场是相遇中心，个人空间提供归属，咖啡馆提供停留，活动场地提供共同目标。先让紧凑空间里有可发现的东西、有可回应的人，再逐步开放新区域。人物行走距离应服务活动节奏。

浏览器 Demo 优先短会话：每次几分钟能完成一个小目标。暂不引入现实时间强制等待、大规模地形编辑、庞大配方树或多种货币。先用少量物品和一个可摆放区域，验证收集—建设—展示是否真的让玩家想邀请别人来看。

## 验证问题

1. 玩家是否愿意在没有排行榜奖励时继续停留？
2. 玩家是否会主动去看朋友的空间、赠送物品或留下留言？
3. 收到挖角反馈时，玩家感到有趣，还是觉得积累被破坏？
4. 不同时在线的两个人，是否仍能感到对方来过？

这些需要真实试玩观察；当前不声称已验证留存、社交意愿或长期经济平衡。
