# 模式定案：职场成长与园区社交

根据最新反馈，取消个人空间布置、家具收集与房屋升级。参考动森的部分收敛为自由探索、偶遇和轻松互动，长期目标由职场晋升承担。

**主循环：逛园区认识同事 → 组队做项目 → 积累业绩 → 晋升 → 接更有挑战的合作项目。**

最后一步的多人共同项目属于后续开发；当前版本是自由探索、招募、个人短项目与轻量社交。首轮晋升后端已实现，前端入口待 Claude 接入。不得把计划中的合作项目、解锁区域当成现有功能。

## 三件核心操作

玩家只需要理解“走、做项目、找同事”。晋升是项目成长的结果，使用工牌上的进度和一个晋升按钮呈现。首次进入保留一句走路提示；经济公式、分账、技能明细进入详情再看。

- **走**：自由逛共享园区，遇到真人，挥手、聊一句、碰杯。
- **做项目**：先用15秒单输入项目熟悉操作，获得金币和业绩。
- **找同事**：招募有不同能力的虚拟分身，形成三人小队。保留现有加价挖角与补偿规则。

金币用于招募；业绩是累计成长记录，不是可消费货币。升职不扣金币，也不因被挖角、队友离线或一天未登录而降职。

## 晋升规格（Demo 初始参数）

每个服务端核验成功的非陷阱任务 +10 业绩；一局至少命中一个有效任务才计为一个有效项目。以下两项条件都要满足，不能靠空局刷次数。业绩累计保留，逐级晋升，不收费。

| 职级 | 累计业绩 | 有效项目 | 晋升后的项目收益加成 |
| --- | ---: | ---: | ---: |
| 职场新人 | 0 | 0 | 0% |
| 项目专员 | 60 | 1 | +5% |
| 团队主管 | 250 | 3 | +10% |
| 部门经理 | 600 | 6 | +15% |
| 合伙人 | 1200 | 12 | +20% |

首次晋升可在一局完成6个有效任务后触发，给首次会话一个明确的高潮。后续门槛是压缩后的 Demo 节奏，尚未根据真实留存或经济数据调优。

收益加成与队友收益技能按百分点相加：例如队友 +25%、专员 +5%，新项目合计 +30%。开局锁定，进行中的项目不被晋升或挖角改写。金币交易、分身分红、碰杯均不产生晋升业绩，避免资产流转代替项目成长。

## 如何更有职场感

空间设计服务工作关系，每个区域都给玩家一个理由走过去：

| 现有区域 | 职场用途 | 实现状态 |
| --- | --- | --- |
| 共享广场 | 看到在线同事、碰杯、查看队伍 | 已有 |
| 项目区 | 接短项目、积累金币与业绩 | 项目已有；晋升后端已接入 |
| 人才街 | 找有不同技能的合作伙伴 | 已有 |
| 咖啡区 | 休息、相遇、短句交流 | 已有基础互动 |
| 办公区 | 团队活动与人物工作表现 | 已有；晋升庆祝待前端 |
| 露台 | 自由探索、休息、遇人 | 已有；不增加装修玩法 |

不增加复杂审批、考勤、饥饿值或日常KPI清单。职场感来自项目分工、成长身份、合作关系和“今天我来带队”，保持卡通、轻松的表达。

## 晋升需要逐步打开玩法

首轮用真实生效的收益加成和公开职级工牌跑通成长循环。后续优先做一个可验证的玩法升级：主管能发出双人项目邀请，两个人各做一项短任务，服务端分别记录贡献、结算团队结果。双方自愿加入，各拿自己的业绩，不把另一人在线当作基础晋升的硬条件。

经理阶段再考虑跨组项目、短时团队目标和新的任务地点。先验证“认识别人 → 愿意一起做一次项目”，再扩展内容。

## 社交与挖角

真人是独立玩家，交易对象保持为明确标记的虚拟分身。被挖走的是小队能力，玩家的职级和业绩保留。这样既有竞争事件，也有不被抢走的长期成长。

挖角继续保留，本次不迁移合同经济。完整的合作项目尚未实现，不能用当前的碰杯奖励代替共同项目验收。

## 前端验收重点

1. 常驻界面只增加“职级 + 一条晋升进度”，不铺开五个阶级的管理面板。
2. 完成项目显示“金币 +X，业绩 +Y”；进度来自服务端。空局明确无业绩。
3. 达标出现“晋升”主要动作；成功后换工牌，进行约2秒庆祝，玩家仍可自由走动。
4. 双浏览器能看到对方新职级；刷新保留成长，不把原种子职业 title 当作游戏职级。
5. 下一局展示“团队 +25% · 职级 +5%”，总计使用真实开局快照，结算预览与服务端一致。
6. 不出现家具、装修、个人房屋升级入口；既有草地、桌椅属于场景美术。

当前前端仍由本机 Claude 负责，其额度已用尽；已确认的地面遮挡问题也尚未修复。晋升页面完成后，需重新进行真实网页验收。
