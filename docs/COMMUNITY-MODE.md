# 娱乐、养成与交友：当前模式

最终目标是晋升，拿更多年终奖，兑换道具、培养并展示自己的队伍。员工来这里轻松玩，职场题材负责身份反转和熟人笑点。

**雇个老板 → 自由逛园区、遇见同事 → 玩短小游戏 → 成长晋升 → 年终领奖 → 给自己和老板买喜欢的东西。**

## 当前可玩的循环

- 四个明确标记的体验身份，各600金币。张总在广场待命，初签300金币，收益技能+25%；其余角色提供时间、救场或收益加成。
- WASD、点击地面与地图寻路，三人小队跟随。真人彼此能看到移动、工牌、换装、表情和短句。
- 「老板来接招」基础15秒：礼物进圈时按空格/点击接住，避开大饼。Boss、咖啡、礼物和救场表达取代工作任务面板；本轮只有这一种小游戏。
- 命中+10成长值；空局不计有效场次。达标可晋升，成长不消费，不因失败或被挖角下降。
- 3场有命中的小游戏算一个演示年。年终奖自动入账，派对弹窗可直接去商店；退出或刷新保存进度。
- 商店有6种永久收藏：两件衬衫、两副眼镜、两种光环。可给自己或老板穿戴/卸下，3D试衣间与园区使用同一个人物模型，其他客户端看到真实穿戴状态。

场景保留咖啡馆、人才街、办公室、俱乐部、露台与派对台。没有装修、家具收集、个人房屋升级。

## 晋升与奖金

| 职级 | 累计成长值 | 有效游玩 | 年基础奖金 | 下一局收益加成 |
| --- | ---: | ---: | ---: | ---: |
| 职场新人 | 0 | 0 | 300 | 0% |
| 项目专员 | 60 | 1 | 450 | 5% |
| 团队主管 | 250 | 3 | 650 | 10% |
| 部门经理 | 600 | 6 | 900 | 15% |
| 合伙人 | 1200 | 12 | 1200 | 20% |

金币是唯一可消费货币，成长值只用于晋升。以上是压缩的Demo参数，未验证长期经济平衡或留存。

每年奖金 = 基础奖金 × (100 + 队伍与职级加成 + 游玩加成 + 同事碰杯加成) / 100，向下取整。

- 基础奖金按本年第一场有效结算时的职级锁定，本年中途晋升从下一年改变基础奖金。
- 队伍与职级加成：三场各自锁定的 `run.skills.incomePct`，每场最多30%，取整数平均。
- 游玩加成：每场 `min(有效命中数,20)`，三场取整数平均，最高20%。
- 同事碰杯：本年与在线近身同事成功碰杯，+10%，重复碰杯不叠加。
- 总奖金加成最高60%。每局即时金币仍按原有真实计分发放；年终奖是额外大额奖励。

已完成的实际示例：新人年基础300，三局技能25/30/30，命中14/7/20，再加一次同事碰杯。加成取整为28%、13%、10%，最终年终奖453金币。详见[本轮实机验收](REVIEW-V3.md)。

## 老板养成的边界

已实现老板跟随、待命台词、工作/庆祝动作、真实收益技能，以及给老板换装。当前重点是先跑通「领奖金→买道具→展示」的反馈。

以下是后续目标，不能当作当前功能宣传：数值培养与技能树、非独占老板分身收藏、每队最多一位老板、入场试用老板、不同老板的完整性格事件、双人小游戏、好友申请/长期关系与借调。

当前交易仍沿用原有初签/加价挖角/90%补偿/5%分红，未完成非独占角色池与自愿借调迁移。队员归属变化不影响玩家的职级、成长、已购道具和已发年终奖。

## 下一阶段的内容顺序

先增加一个真正需要两人配合的短游戏，再做老板能力培养与朋友借调。通过真实试玩判断小游戏是否有趣、玩家是否愿意互邀、奖金是否带来继续玩的动力。首轮不加入复杂审批、考勤或日常KPI面板。
