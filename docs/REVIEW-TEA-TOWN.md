# 赛博小镇 · 大地图救店验收

日期：2026-10-21（用户时区）。本轮按最新反馈恢复自由探索的大地图：招募与奶茶经营是地图里的地点，取消原先强制切换的两页面与固定招人教程。

## 交付动线

进入原广场 → 手机收到“街角奶茶快倒闭了”的求助 → 可接任务或先逛逛 → 自选去广场招0–2位同事 → 沿真实寻路到奶茶小镇店门 → 走近后交互进店 → 筹备与正式营业 → 真实金币收入 → 手机查任务/账本 → 回地图探索、消费升级。

原90×66地图、办公室、广场、花园、夜市、外环街道、人物及行走/小地图/摇杆均保留。奶茶店门面位于原咖啡亭位置，碰撞不改；广场增加可选招募看板，地图标记两个地点。导航只设置步行路线，不瞬移，不自动接任务或开店。旧公司电影不再自动播放，避免进入新世界时发生看不见的输入锁。

同事全自动；主角一批最多3单/12模拟秒、可排下一批，完成后待命。首班240模拟秒、20位客人、12杯达标，备货20/40/60，短班工资为标准工资四分之一向上取整。四位演示主角分别用0/1/2同事的12种组合均能盈利；招人后减少主角指派，允许两个专业同事完成全班而主角不操作。

## 独立验证

- **桌面真人UI**：可暂缓任务、P开关手机、M地图、接任务、不招人步行进店、打开手机暂停营业、离店暂停、刷新续同一场、完成任务、返回地图查账、真实升级和刷新保持，全部跑通。正常速度独自实际出杯19、指派20批，净增340金币，无页面异常。
- **手机真人UI**：390×844，在广场选两位同事，真实步行到店，完整营业不指派主角任何一批；实际20杯、净增240金币、手机任务完成，无横向溢出或页面异常。手机为Chrome视口模拟，尚未验证实体设备。
- **正常画质/声音**：街区→筹备→营业→高峰→结算→回街区配乐切换，音乐静音与恢复、跳过不爆发音效、免费试营不能完成有薪救店任务。
- **服务端核心**：4组测试（含12个组合子用例），覆盖任务不可伪造、接受幂等/并发、独自可盈利、雇佣可选、练习与空转不完成任务、钱包与流水、升级权限；全Go竞态及前端类型/规则/音乐检查通过。
- **dsh公开HTTP Agent**：真实接受任务、0同事正式开门、逐步按队列指派、实际结算、对账、终局幂等、读取回放、付600升级与重试/刷新保持，全部通过。不读取SQLite或使用客户端模拟。

金币只有一套，复用原players.coins和ledger。独自营业案例：2000，预付240后1760，销售380+首达标奖200后2340，净增340；升级花600后1740。两位同事案例工资合计120，预付360，营业400+奖金200后2240，净增240。工资、预付、收入、补助与升级可以在手机收支里核对；重复接受任务不发钱，重复结算/升级不重复转账。

升级完成页只显示本次真实金币、杯数与等级，移除旧8/18/80教学记录；独自经营不再显示“同事接管日常”。地图门面随等级改变，旧NPC价格在小镇模式隐藏以免混淆短班工资。手机可Esc/P/关闭按钮收起，并约束键盘焦点；打开手机取权威钱包数据且暂停店内推进。
