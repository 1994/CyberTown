# Codex 独立验收记录

用户要求分工：Go 服务端由 Codex 实现，React/Three.js 前端由本机 Claude Code 实现；Codex 负责协调、复核与 GitHub 交付。验收依据是用户聊天中贴出的规格，未收到其提到的16页完整版GDD，因此没有宣称对缺失文档逐条验收。

## 独立实际操作

在生产构建的 Go 服务器、独立数据库、独立页面中通过可见 UI 进行操作，未直接改金币或注入游戏状态：

1. 老王初始600，实际进行15秒小游戏，点击2张有效任务卡，获得18，余额618。
2. 老王花300签约张总，余额318；角色从电梯入职，工位技能显示收益+25%。
3. 小李初始600，以380挖张总，余额220。老王页面实时变成660（318+342），团队技能回到0，角色保留并演出离职。
4. 老王花300签约小李分身，余额360。小李页面从220变235，收到+15分红提示，消息中心有真实成交记录。
5. 检查数据库中的3笔交易及项目奖励，金额与上述UI操作完全一致。证据摘要：`artifacts/verification/independent-ui.json`。

浏览器控制台未出现 error，仅有 Three.js 依赖中 Clock 弃用的 warning。这里的15秒挑战测试结果不是满分演示，也没有向客户端输入奖励值。

## 独立服务端检查

实际运行 Go 单元/HTTP测试、`go test -race ./...`、`go vet ./...`。覆盖报价校验、90%/5%整数分账、满员和余额、多个并发请求/独立连接抢购、事务中途故障回滚、提前与重复领奖、跨账号项目、过期状态持久化、三类技能快照、SSE与注销、重启持久化、账本守恒、静态路径与符号链接边界。

`backend/testdata/rules-contract.json` 中36组随机任务及计分样例，与 Go 实现逐项对照；`npm run test:contract` 同时验证当前 TypeScript 实现与样例一致，避免单侧规则悄然改变。

## 发现并返工

- 服务端曾允许省略报价：已强制有限正整数报价，变价返回409，防止未确认新价的并发连续成交。
- 过期项目曾在事务内抛错导致过期状态回滚：Go实现先提交过期，再返回410。
- 静态文件路径前缀校验：已改为真实目录边界检查，包含编码路径与符号链接回归测试。
- 签约后市场遮挡电梯：已自动收起，并复验角色入场。
- 双人指南资金不足：已改为先挖角、赚钱至少80，再签约分身。
- 低帧率时补偿牌提前遮挡收拾动作：已按角色实际位移更新；复看截图可见收拾与搬纸箱离开。
- 手机上3D名牌盖住消息正文：已将场景放入独立层叠上下文，并在生产构建390×844浏览器中重新打开消息，确认标签不再覆盖正文。
- 浏览器测试启动器曾拼接 shell 删除路径：已替换为参数数组启动Go、专属临时数据库与定向清理。
