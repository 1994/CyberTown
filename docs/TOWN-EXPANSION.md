# 探索与商业成长

本轮按新的地图要求扩大可行走边界：`x=-90..90、z=-66..66`，面积由 5,940 增至 23,760 平方米。中心广场出生、可选招募、首店入口的位置保持不变，第一章不用走遍全镇。

商业街连接西街集市、河港商埠；娱乐街连接星光乐园、滨河步道。四处据点可以真实步行到达，玩家主动考察后获得客群说明和一次性 30 金币奖励。每个账号每处只奖励一次，共 120 金币。远处点击、重试、刷新和并发请求不能重复领奖。任务仍从手机领取，考察不会自动接奶茶任务或开店。

考察目录集中在 `gameplay/town-opportunities.json`，Go 与前端读取同一份坐标和奖励。服务端根据已登录玩家的世界位置验证距离，数据库 `town_explorations` 持久化记录，奖励和金币流水同事务提交。扩表为追加迁移，保留已有营业和钱包数据。

`GET /api/tea/home` 新增 `exploration`（四处状态、已得奖励、首店完成与连锁选址条件）。`POST /api/tea/explore` 只接收 `{ "siteId": "west-market" }`，要求已登录；新考察超出4.2米返回409，未知据点返回400。已记录的考察可安全重试，金币流水原因是 `town_explore`。成功后通过既有同步事件刷新经济快照。

手机“版图”显示成长方向：首店站稳 → 考察商圈 → 连锁扩张 → 商业帝国。当前可完成的是首店篇和四处考察；两项都完成才显示“连锁选址就绪”。多店购买、跨店员工调度和集团收入属于后续章节，目前不提供无法生效的购买或收益按钮。

首店原有三阶段经营、开店确认、员工自动工作、玩家半自动补位和结算报表保持原规则。`business.stage=complete` 为兼容协议保留，其含义明确为“首店篇完成”。

验收证据位于 `artifacts/town-expansion/`，覆盖实际步行、地图布局、探索奖励、存档、旧经营回归及预览库保护。
