# 赛博小镇 · 首店经营主线（tea.4）

玩家在大地图自由行走。招募和经营分别位于广场与奶茶小镇，通过手机求助、真实寻路和门口交互串起首店篇。新增探索与连锁成长方向见 [探索与商业成长](TOWN-EXPANSION.md)。

## 可玩动线

1. 企业 SPI 认证后确认本人姓名、头像，点击“进入小镇”落到私人小镇广场；演示环境才有体验身份选择。首次到达显示位置、本人和移动提示，点击“查看手机消息”读取店长求助，也可直接先逛地图，不自动接任务或开店。
2. 在手机接下“救救街角奶茶”，任务与金币收支由服务端保存。带路只设置真实寻路；WASD、点击地面、摇杆和小地图仍可自由使用。
3. 招募是可选项：到雇佣大厅签约、派杂活培养同事分身，Lv2召回后入店选0–2名店员，也可以独自直接去店里。无招满人数或旧教学门槛。
4. 沿地图走到奶茶小镇的街角奶茶门口，交互进入筹备。选择岗位、原料和策略，查看阶段目标与费用。正式和免费试营业都先弹开门确认；点击“准备好了，开始营业”才建立营业局，正式班同时预付金币。取消确认不扣款。
5. 主角按批次接待/制作，同事持续全自动。自然营业结束后自动弹出经营报表，展示净赚、出杯、到店、流失、实际曲线及收入成本明细；本班净增金币为正时完成救店任务。报表分别说明预付已扣、实际到账与结算后钱包。
6. 从报表回筹备、回小镇，或用金币升级；回筹备不会自动开下一班。街上门面改变，刷新保持。之后继续正式营业，依次完成霓虹奶茶与旗舰店目标。

原办公室、花园、夜市、外环街道等地图均保留。奶茶店使用原咖啡亭的建筑位置与碰撞，门口交互点(-19.4,-1)；广场招募点(-5,12)。走到交互范围才可进店或打开招募。店内可以返回地图，进行中的营业暂停，回来继续同一场。

## 入镇与相遇

新玩家落在私人小镇广场喷泉北侧，企业身份分布在可行走的21格（x=-6至6，z=10.5至12.5），避开长椅与喷泉。已有世界位置再次进入时继续使用，不因身份确认重新传送。收到服务端本人坐标之前锁住移动；“正在进入小镇”“重连中”与实际在线状态分别展示。

确认进入前不建立世界连接，因此资料确认页上的用户不计入在线玩家。入镇后，同一服务的大地图同步附近真人的角色、姓名、头像和移动；位置条显示所在区域、本人姓名和附近玩家数量（不包含自己与NPC），展开可查看附近玩家。服务按距离发送附近角色，并非把全部员工目录都画到同一屏。玩家断开后移除名牌与附近列表记录。

入镇操作指引明确展示移动方式和手机位置：电脑点击地面/WASD移动，点右上角手机或按P查看任务与钱包；触屏用摇杆/点地面和手机按钮。引导时手机高亮，可用“查看手机消息”直接打开，也可“先逛逛”。右上角“操作指引”（?）随时重看，不锁走路、不强制接任务或招募。

本版指引使用v2记录，旧版已关闭或已接任务的地图玩家仍会看到一次新版说明；关闭或打开手机后，同一环境、浏览器与玩家刷新不再重复。店内旧存档继续恢复同一班营业，不强制回广场。手机求助保留红点入口，由玩家决定接取。小镇默认只有镇主与已签约的员工分身；别人的镇是独立房间，互访入口在后续阶段实现。

## 首班与金币

救店短班使用20位舒缓顾客、240模拟秒（默认约60秒实播）、12杯达标；按真实角色能力运算。自己最多一批3单/12模拟秒，最多排下一批；员工不用再次点名。四个演示主角独自营业均能盈利，同事增加后所需操作减少。

金币只有一套：复用原players.coins及ledger。原开店补助1400只发一次，体验角色原600合计2000；重复接任务不发钱。20份备货原料120+运营120，员工短班工资为标准工资的四分之一向上取整。正式开门先预付，结束再收每杯20的销售收入及日首次达标奖200，并给真实员工发工资；失败也付工资。免费试营不改变金币和有酬名额，也不能完成有薪救店任务。

手机钱包显示权威余额和最近30笔真实流水：补助、开店预付、销售/奖金、工资、升级及既有金币动作。任务完成保存关联runId和净增收入，不能客户端自行领取或重复完成。正式每天3班、真人员工有酬名额每天3次、公开受雇需本人授权。首次救店完成可解锁600金币焕新，不强迫做旧72杯高峰。

## 协议与兼容

- `GET /api/tea/home` 返回mission、wallet、business、员工、门店及可恢复营业ID。business包含当前目标、进度、挑战、合法备货与升级资格。
- `POST /api/tea/mission/accept` 幂等接任务，不发奖励。
- `/api/tea/sessions` 的新lesson为 `rescue`，支持0–2同事；推进与读取接口沿用，受服务端revision/requestId校验。
- 旧tea.1/tea.2/tea.3历史与进行中的营业保留冻结规则，可恢复或回放；原钱包、数据库及存档不重置。新增经营进度表通过加表迁移，不清库。

## 人工首轮验收

1. 确认本人资料后进入私人小镇广场，手机求助可以暂缓；玩家不会被自动接任务或自动开店。
2. 接下任务后，自选签约和培养员工，单班带0–2位店员，再沿地图步行到店。筹备可改岗位、备货和策略；取消开门确认不扣金币。
3. 最终确认才预付开店。主角手动指派批次，同事自动工作；离店、看手机或刷新后可以继续同一班，不重新付费。
4. 自然结束自动弹报表，核对净赚、成本、到账和钱包；历史列表的净赚包含同一笔达标奖，回看不再次入账。
5. 首班救店后，手机显示当前经营目标。依次投入600/1200金币升级，店面、客流、售价和目标一起变化，完成旗舰目标后显示首店篇完成；手机版图继续展示商圈考察及后续连锁方向。
6. 正式次数用完或金币不足时显示原因，免费试营业仍可使用。每天正式3班；测试错误计划可先免费试营。旧档继续保留，新手线应选尚未完成救店任务的身份。

异常回归覆盖开门和升级回包丢失、营业推进两次失败、刷新恢复、双击防重，以及完整三段经营，见 [人工测试前复检记录](../artifacts/tea-preflight/acceptance.json)。本机为演示环境，企业SPI登录使用fixture验证资料与头像回退，真实企业内网认证需在对应环境检查。

本轮优先交付[经营模型和雇佣大厅](PRIVATE-TOWN.md)，取消永久绑定，员工合同可挂牌、撤单和跨镇转让；等级经验保留，买卖使用同一金币账本。原有tea.1/tea.2兼容API的历史用工规则不代表当前私人小镇UI的排班规则。
